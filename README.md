# Multi-Agent Tag AI

A reinforcement learning project built in Unity using ML-Agents where two AI agents compete in a 1v1 game of tag. One agent learns pursuit behavior while the other learns evasion strategies through self-play and reward-based training.

## Features

- Multi-agent reinforcement learning environment
- PPO training using Unity ML-Agents
- Custom reward and observation systems
- Pursuit and evasion AI behaviors
- Training analytics with TensorBoard
- Built with Unity, C#, and Python

## Technologies Used

- Unity Engine
- Unity ML-Agents
- C#
- Python
- PPO (Proximal Policy Optimization)
- TensorBoard

## Project Goal

The goal of this project was to explore reinforcement learning concepts by creating a competitive AI environment where agents improve over time through iterative training and experimentation.
